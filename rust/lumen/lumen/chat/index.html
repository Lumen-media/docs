Live chat system for Lumen’s event experience.

The chat lets the operator and connected audience members exchange text messages, replies, emoji reactions, typing indicators, and file attachments while an event is running. This module is the composition layer: it owns the shared ChatState, wires together persistence from store and local file sharing from file_server, and exposes the Tauri commands used by the desktop frontend.

Every mutation is broadcast twice:

  • over WebSocket to remote devices (via the broadcast_* helpers in store), and
  • as a Tauri event to the desktop webview (chat_message, chat_config_changed, chat_deleted, chat_reaction, chat_typing).
