lumen::chat

Module store 

Source
Expand description

Chat persistence, validation, and WebSocket broadcast helpers.

This module backs the live chat system with:

  • Domain types serialized to the frontend and over WebSocket — ChatMessage, ChatFile, Reaction, ReplyRef, ChatConfig.
  • Persistence — ChatStore keeps a bounded in-memory history and, when enabled, mirrors it to SQLite (tables created by ensure_tables, settings read/written by load_config / save_config).
  • Fan-out — the broadcast_* functions push JSON events to every WebSocket session that holds the chat permission, while send_chat_history and send_chat_error target a single session.
  • Validation — validate_message_text and ChatStore::save_file enforce size, type, and content limits.

All fallible functions return Result<_, String> with short, stable error codes (e.g. "empty_message", "file_too_large") that the frontend maps to user-facing messages.
