Minimal localhost HTTP server for chat file attachments.

Files saved by crate::chat::store::ChatStore::save_file live on disk under the chat files directory. This server exposes them at http://127.0.0.1:{port}/files/{name} so the desktop webview and remote devices can fetch attachments referenced by a crate::chat::store::ChatMessage.

The server binds to an ephemeral loopback port, accepts one request per connection, and only serves plain file names directly inside the files directory; anything else is rejected with 403 or 404. Responses carry Access-Control-Allow-Origin: * so browsers can load them cross-origin.
