Media library: folder synchronization, CRUD, search, and theme management.

This module is the heart of Lumen’s media catalog. It provides:

  • Folder synchronization (media_sync_type, media_sync_themes) that walks configured media directories and upserts file metadata into SQLite.
  • CRUD operations for media files and themes (media_insert, media_delete, media_update_download_status, media_insert_theme).
  • Full-text search across media types (media_search, media_search_multi, media_search_files).
  • YouTube URL resolution via crate::url_media::resolve_youtube and thumbnail caching.
  • Theme catalog management for presentation theming.

§Thread safety

MediaStore wraps a rusqlite::Connection in a Mutex, making it safe for concurrent access from Tauri commands. Each command locks briefly for its transaction.

§Database schema

The media_files table stores one row per file with columns for path, size, modification time, extension, media type, duration, artist, searchable content, original URL (for URL-based entries), thumbnail paths, download status, and folder. The theme_files table tracks theme assets separately.

§Frontend commands

All pub functions marked with #[tauri::command] are exposed to the frontend via Tauri’s IPC. They follow the naming pattern media_*.
