Centers window on the monitor it currently sits on, in physical pixels.

The center: true config flag is resolved while the window is being created, which can miss on high-DPI or multi-monitor setups and leave the window at (0, 0) - the splash then shows up in the top-left corner. Centering once the window exists uses the real monitor bounds and the real outer size, so the result is DPI-correct on any resolution.
