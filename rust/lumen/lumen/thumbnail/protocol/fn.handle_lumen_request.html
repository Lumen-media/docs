Asynchronous URI scheme handler for the lumen and lumen-thumb schemes.

Registered in main.rs via register_asynchronous_uri_scheme_protocol for both scheme names; the scheme is detected from the request URI (lumen-thumb enables sized thumbnail processing, lumen serves full-size media).

§Request processing

  1. Strip the scheme prefix (lumen://, lumen-thumb://, or the http(s)://lumen[-thumb].localhost/ form WebView2 produces) and parse the query string into src, w, and q.
  2. Reject requests without src with 400.
  3. Spawn a worker thread that emits lumen:optimizing, runs process, emits lumen:optimized, and answers the [UriSchemeResponder] exactly once.

§Errors

The response status reflects the failure: 400 for a missing src or an undecodable image, 404 when a local src does not exist, 415 for unsupported source types, 500 for cache/IO/encoding failures, and 502 for upstream HTTP failures when fetching a remote source. Failures are delivered as plain-text response bodies through the responder rather than as a Rust Result.
