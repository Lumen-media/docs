Module os_thumb

Expand description

Operating-system thumbnail providers.

Requests a native thumbnail from the platform instead of decoding the file ourselves, which is dramatically cheaper for videos and large images:

  • Windows: IShellItemImageFactory (Shell thumbnail cache) converted from HBITMAP to BGRA pixels.
  • Linux: the FreeDesktop thumbnail cache spec (~/.cache/thumbnails/{normal,large}/<md5 of file:// URI>.png).
  • macOS / other: not supported, always returns None so callers fall back to super::image_thumb or super::video_thumb.

This module is the first resolution step of super::get_thumbnail and of the fast path in super::protocol.
