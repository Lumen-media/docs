Module thumbnail 

Source
Expand description

Thumbnail generation and caching for local and remote media.

The module turns local files (images and videos) and remote image URLs into small, cached JPEG/WebP thumbnails and exposes them to the webview through two Tauri commands plus the custom lumen:// and lumen-thumb:// URI schemes implemented in protocol.

Resolution order used by get_thumbnail:

  1. Return the cached JPEG immediately if <blake3(path)>_<size>.jpg already exists under the app data cache directory.
  2. Ask the operating system for a native thumbnail (os_thumb); on Windows this hits the Shell thumbnail cache, which is by far the cheapest source for videos and documents.
  3. Decode the file in-process: raster images via image_thumb, H.264 videos via video_thumb (symphonia demux + OpenH264 decode of the first decodable frame).

Thumbnails are content-addressed by the BLAKE3 hash of the source path (not the file contents), so moving a file produces a new cache entry.
