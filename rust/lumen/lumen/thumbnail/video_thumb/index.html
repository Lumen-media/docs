lumen::thumbnail

Module video_thumb 

Source
Expand description

Video thumbnail extraction without spawning an external process.

Demuxes the container with symphonia, decodes the first decodable video frame with the OpenH264 library, and writes the frame (fitted to the requested box) as a JPEG. Only H.264/AVC in MP4-family containers (mp4, mov, m4v) is supported; anything else fails with an error so callers such as super::get_thumbnail and super::protocol can fall back to the OS thumbnail provider.

The decoder is primed with the track’s avcC extradata (converted to Annex B) so the first access unit can be decoded without waiting for an in-band parameter set.
