Expand description

Generates (or returns a cached) thumbnail for a local media file.

§Tauri command (frontend API)

Invoke as invoke<string>('get_thumbnail', { path, size? }).

ArgumentTypeDescription
pathstringAbsolute path of the source file.
sizenumber?Maximum edge length in pixels. Defaults to 200.

Resolves with the absolute path of the JPEG stored in the app cache directory (<app-data>/lumen/cache/thumbs/<blake3(path)>_<size>.jpg). The file is created on first request and reused afterwards; delete it to force regeneration.

§Examples

const thumbPath = await invoke('get_thumbnail', {
  path: 'C:\\Videos\\intro.mp4',
  size: 320,
});
// thumbPath === 'C:\\...\\lumen\\cache\\thumbs\\<hash>_320.jpg'

§Errors

Returns an error string when:

  • path does not exist (file not found: ...);
  • the cache directory cannot be created;
  • the file extension is not one of the supported image types (png, jpg, jpeg, webp, bmp, gif) or video types (mp4, mov, m4v), reported as unsupported file type;
  • decoding, generating, or saving the thumbnail fails (the underlying decoder message is included).
