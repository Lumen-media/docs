Module queue

Expand description

Media playback queue for Lumen.

The queue is a persisted, ordered list of playable entries stored in the queue table of lumen.db. Entries are either local files/downloads (identified by file_path) or remote URLs and triggers, which use synthetic paths:

  • url entries keep the canonical video URL in file_path and track download state (not_downloaded, downloaded, missing);
  • trigger://{entry_id} entries represent automation triggers rather than playable media and are managed by dedicated commands.

Ordering is controlled by the integer position column; the Tauri commands in this module add, remove, reorder, shuffle, mark as played, and update metadata. QueueStore wraps the shared SQLite connection in a tokio::sync::Mutex.
