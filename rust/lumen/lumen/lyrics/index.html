Module lyrics 

Source
Expand description

Parser and serializer for Lumen’s plain-text lyric format.

A lyric file is markdown-like: a --- frontmatter block holds display metadata (name, author, font, animation, …) and the body holds one slide per paragraph, with slides separated by two empty lines. A slide may start with an <!-- bg: path --> comment that overrides the background for that slide only.

Parsing is tolerant by design: missing frontmatter, unknown keys and unparsable numbers simply fall back to defaults, so a hand-written file always opens.
