Small shared helpers for remote-facing features.

Remote control, URL media and device discovery all need the same things: a directory for cached thumbnails, a millisecond timestamp and an HTTP client that cannot hang or buffer unbounded data. Every fetch issued from here is bounded by a timeout and by a maximum body size.
