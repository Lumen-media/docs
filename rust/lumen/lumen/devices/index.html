Module devices 

Source
Expand description

Device pairing and remote-control session management.

Remote clients (phones/tablets) connect to the local WebSocket server, pair with the desktop by presenting a short-lived registration token, and then receive permission-gated player, lyrics, streaming and chat events. Registered devices and their permissions are persisted in the app’s SQLite database (lumen.db) so they survive restarts; the pairing token itself is held only in memory and expires 15 minutes after generation.

The Tauri commands in this module form the frontend’s device-management API (list devices, toggle them, edit permissions, configure remote access), while the free functions are called by the WebSocket server when a client registers, authenticates or sends events.
