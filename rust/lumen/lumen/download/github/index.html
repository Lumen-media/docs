lumen::download

Module github 

Source
Expand description

Release-asset resolution for the external tools and app resources.

All network access is done with the reqwest async client using a lumen-app user agent. Two kinds of sources are used:

  • GitHub releases (api.github.com) for yt-dlp (nightly builds) and FFmpeg (BtbN builds), matched to the host platform by platform_key.
  • Other publishers: Node.js (nodejs.org) and the lumen-locales repository served through jsDelivr.

GitHub’s unauthenticated API is rate limited; a 403 is surfaced as a human-readable error so the UI can ask the user to retry later.
