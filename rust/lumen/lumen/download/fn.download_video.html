Starts a yt-dlp download for url and returns immediately.

§Tauri command (frontend API)

invoke('download_video', { url, provider, quality, maxHeight? }) returns a DownloadResult whose download_id identifies the job; the other fields are placeholders (file_path/file_extension empty, file_size 0) until the download completes. The real outcome arrives through events:

  • video-download-progress - { download_id, progress, speed, eta, status }
  • video-download-complete - the finished DownloadResult
  • video-download-error - { download_id, message, code }

§Errors

Returns an error string when the provider is not youtube, yt-dlp is not installed, FFmpeg is missing on macOS, or the downloads directory cannot be created or the process cannot be spawned. Behaviour is otherwise delegated to downloader::start_download.
