pub async fn download_dependencies(app: AppHandle) -> Result<(), String>
Expand description

Downloads or updates all external tools as needed.

Emits dependency-download-progress and dependency-download-complete events on the Tauri app for each step:

  • yt-dlp: updated only if missing or version differs from latest release
  • ffmpeg/ffprobe: downloaded and extracted on Windows/Linux when missing (skipped entirely on macOS)
  • node: downloaded and extracted when missing

On success the temporary downloads staging directory is removed.

§Errors

Returns an error string when any step fails (cannot create directories, fetch a release, download a file, extract an archive, move files, or persist versions); in that case the staging directory may be left behind.
