lumen::download

Module dependencies 

Source
Expand description

Dependency provisioning: manages external tools under the app’s tools directory.

The state (installed versions and paths) is persisted as versions.json in <tools-dir>. Three tools are provisioned on demand:

  • yt-dlp - downloaded from the nightly GitHub releases; updated whenever the installed version differs from the latest release.
  • ffmpeg/ffprobe - extracted from BtbN GitHub release ZIPs on Windows and Linux. On macOS this module does not download FFmpeg (the dependencies install step skips it and expects ffmpeg on PATH).
  • node - downloaded as a Windows x64 ZIP from nodejs.org/dist/index.json (picks the latest LTS, falling back to the newest release overall).

Progress/completion notifications are emitted through the Tauri event system: dependency-download-progress and dependency-download-complete. These events are consumed by the frontend UI.
