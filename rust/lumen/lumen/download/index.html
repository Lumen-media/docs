Module download

Expand description

Media download subsystem: external tool provisioning, video downloads, and YouTube cookie management.

Three concerns live behind this module, each in its own submodule:

  • dependencies - detects, downloads, and versions the external tools (yt-dlp, ffmpeg/ffprobe, node) under <app-data>/tools.
  • downloader - spawns yt-dlp to download videos/audio, streams progress events, and manages cancellation and cookie validation.
  • github - resolves release asset URLs from GitHub/Node.js endpoints.

DownloadState is created once during app setup with initialize_download_state and registered with Tauri’s state manager so every command below can reach the shared tools directory and the set of active downloads.
