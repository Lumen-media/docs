lumen::download

Module downloader 

Source
Expand description

yt-dlp-backed media downloading, progress reporting, and cookie validation.

Downloads are executed by spawning the yt-dlp binary provisioned in the tools directory (see super::dependencies). A download is identified by a UUID (ActiveDownload::download_id) and tracked in the shared ActiveDownloads map so it can be inspected or cancelled while it runs.

Lifecycle and events:

  1. start_download validates prerequisites, spawns the process, records it in the map, and returns an initial DownloadResult immediately.
  2. A background task parses yt-dlp’s stdout and emits video-download-progress (DownloadProgress) for each progress line.
  3. When the process exits, the file is moved from the temporary downloads directory to the user’s media directory and either video-download-complete (DownloadResult) or video-download-error (DownloadError) is emitted. Auth-shaped yt-dlp failures are classified as auth_required with a cookies hint.
  4. cancel_download kills the process and removes the entry; cancelled jobs emit no completion event.

Authentication comes either from a cookies.txt file installed through install_cookies_file (copied to a temp file per run) or, when no file exists, from the first logged-in browser detected by detect_youtube_browser.
