Expand description

Starts a yt-dlp download and returns immediately with a job id.

Only the youtube provider is supported. The function verifies yt-dlp is installed, resolves FFmpeg (on macOS it must already be on PATH), builds the format selector from quality (or max_height when set and not audio-only), attaches authentication, spawns the process, records it in active_downloads, and launches the background task that streams progress and completion events.

The returned DownloadResult is a placeholder carrying the new download_id; the real outcome is delivered through the video-download-progress, video-download-complete, and video-download-error events.

§Errors

Returns an error string when the provider is not youtube, yt-dlp is missing, FFmpeg is missing on macOS, the downloads directory cannot be created, or the process cannot be spawned.
