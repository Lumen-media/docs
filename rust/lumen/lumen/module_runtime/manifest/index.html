Module manifest 

Source
Expand description

Manifest schema and loading for Lumen modules.

Every Lumen module ships a manifest.json file at its root. This module defines the on-disk shape of that file (ModuleManifest) together with its optional sub-objects (ModuleAuthor, ModulePermissions), and provides the loading/validation entry point load_manifest.

The manifest is the single source of truth used by the installer, the registry, the network permission checker and the module store, so the validation rules implemented here are security-relevant: they reject empty or non reverse-DNS identifiers before any path derived from the manifest id is created on disk.

§Examples

let json = r#"{
    "id": "com.example.hello",
    "name": "Hello",
    "version": "1.0.0",
    "api": "1"
}"#;
let manifest: ModuleManifest = serde_json::from_str(json).unwrap();
manifest.validate().unwrap();
assert_eq!(manifest.entry_file(), "main.js");
