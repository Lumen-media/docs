Module themes 

Source
Expand description

Theme image imports for modules.

Modules use backgrounds and other imagery through the shared theme_files table in the main Lumen database. module_theme_add lets a module import an image either from a URL (subject to the same network permissions as crate::module_runtime::net) or from a path inside its own directory, then copies it into the themes media directory and records a row.

Imports are content-hashed with BLAKE3: re-importing the exact same bytes returns the existing row instead of writing a duplicate. Filenames are sanitized and uniquified on disk. Imported files are served back to the webview through the lumen-module://__theme/id/{id} route (see crate::module_runtime::protocol).
