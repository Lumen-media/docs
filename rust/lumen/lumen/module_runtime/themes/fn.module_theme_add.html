Tauri command: imports an image into the shared themes store for a module.

§Frontend API

invoke("module_theme_add", { moduleId, input })

The module must exist and be enabled. For URL sources the download is subject to the module’s network permissions and a size cap; for file sources the path is scoped to the module directory. The image is content-hashed so duplicate imports return the existing entry.

§Errors

Returns an error when the module is missing/disabled, its manifest cannot be loaded, the source is unauthorized or outside the module directory, the download fails, the image type is unsupported, the size cap is exceeded, or any filesystem/database operation fails.
