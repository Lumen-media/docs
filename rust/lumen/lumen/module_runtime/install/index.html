Module install 

Source
Expand description

Module installation from .lumenpack archives or directories.

Installer copies a module into the modules root and registers it. Two sources are supported:

  • a .lumenpack file, a ZIP archive containing manifest.json plus the module payload, extracted after validating every entry path;
  • a directory, either copied into the modules root (sideload) or referenced in place (dev_mode, so the developer’s build output is served live).

Both extraction routines treat the archive and the manifest id as untrusted input. resolve_module_dest and resolve_archive_entry reject absolute paths, ../~ segments and any path that would escape the destination directory (Zip Slip), and every rejection is covered by the unit tests in this file.
