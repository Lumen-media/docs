Module store 

Source
Expand description

Community module store: catalog, releases, READMEs, downloads and installs.

The store is driven by a static JSON catalog published on GitHub (CATALOG_URL). From a catalog entry the store can resolve the module’s latest GitHub release, download its .lumenpack asset, and hand it to Installer to produce an InstalledModule.

Two on-disk, best-effort caches live under <app_data_dir>/lumen:

  • catalog.json — the last successfully fetched catalog, served with stale = true when the network is unavailable;
  • store-cache/releases/{repo}.json — the latest release per repository, reused for RELEASE_TTL (one hour) and as a fallback on rate limiting.

Downloads are streamed with progress emitted on the store:download-progress event and are hard-capped at MAX_PACK_BYTES. All functions here are Tauri commands exposed to the frontend.
