Module net 

Source
Expand description

Permission-checked HTTP proxy for modules.

Modules cannot reach the network directly; they issue requests through the module_net_request Tauri command, which enforces a layered policy before any connection is opened:

  1. only https URLs are accepted;
  2. private, loopback, link-local, multicast and .local/.localhost hosts are always blocked (see is_private_host);
  3. when the manifest declares permissions.network, the URL must match one of the patterns (see match_url_pattern);
  4. hop-by-hop and security-sensitive request headers are rejected, request bodies are limited to methods that allow them, and the response body is capped by max_bytes.

Responses are returned as a ModuleNetResponse; all failures use the stable, machine-readable ModuleNetError shape.
