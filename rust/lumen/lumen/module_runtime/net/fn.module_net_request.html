Tauri command: performs a permission-checked HTTP request for a module.

§Frontend API

invoke("module_net_request", { moduleId, input })

module_id must be a registered, loadable module; its manifest permissions.network patterns gate the target URL. The request is executed with the shared crate::module_runtime::ModuleRuntime HTTP client and the decoded result is returned as a ModuleNetResponse.

§Errors

Returns a ModuleNetError when the module is unknown, its manifest cannot be loaded, the URL fails check_url_allowed, the request cannot be built, the transport fails/times out, or the body exceeds max_bytes.
