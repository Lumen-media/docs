Module background_presets

Expand description

Generator presets owned by Rust.

One pretty-printed <id>.json file per user preset lives under <base>/config/background-presets/; built-ins are defined in code and merged with the user list. Every parameter is validated and clamped against the catalog before it is persisted, so the webview can never introduce an effect or a value the engine does not understand.
