Initializes the streaming subsystem and registers its state with Tauri.

Boot sequence:

  1. Ensures the config directory exists.
  2. Creates the WebRTC [MediaEngine] and interceptor registry and builds the [webrtc::api::API].
  3. Loads or creates the persisted StreamingConfig and starts the HtmlServerRuntime if enabled.
  4. Creates all static local tracks (H264 for preview/app_preview/main and the RTP passthrough for mobile preview video).
  5. Stores the StreamManager inside an Arc<Mutex<_>> wrapped by StreamingState.
  6. Starts the crate::streaming::app_preview_producer background task.
  7. Emits the initial streaming_status_changed event.

§Errors

Returns the underlying error message if storage cannot be prepared, WebRTC setup fails, or the config cannot be loaded/written.
