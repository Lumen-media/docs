Shared streaming state and the Tauri commands exposed to the frontend.

This module owns StreamManager, the single source of truth for every WebRTC artifact produced by the desktop app: local media tracks, the peer connections currently subscribed to each stream, connected mobile peers, per-device volumes and the HTML presentation server runtime. It is stored inside a StreamingState and registered as Tauri managed state during setup by initialize_streaming_state.

The functions annotated with #[tauri::command] at the bottom of the file are the frontend API: they are invoked from the desktop webview through @tauri-apps/api invoke() and mirror the TypeScript wrappers in src/services/streaming-service.ts. Remote devices never call these commands directly; they use the WebSocket signaling helpers in crate::streaming::signaling.

§Events emitted

  • streaming_status_changed - emitted by StreamManager::emit_status after any mutation, carrying a StreamingStatus snapshot.
  • mobile_stream_ended - emitted by cleanup_session when a mobile device stops sending, carrying { device_id }.
