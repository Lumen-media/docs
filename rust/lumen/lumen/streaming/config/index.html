Module config 

Source
Expand description

Persistent streaming settings and the runtime status snapshot.

StreamingConfig is the user-editable configuration stored as config/streaming.json under the app base directory. It is round-tripped through the Tauri commands in crate::streaming::manager and is always passed through sanitize_config before being saved or applied, so out of range values coming from the frontend can never reach the runtime.

StreamingStatus is a read-only projection of the live crate::streaming::manager::StreamManager (subscriber counts, mobile connection state, HTML server URL and current volumes) that the frontend polls or receives through the streaming_status_changed event.

All fallible functions return Result<_, String> carrying a raw I/O or serialization error message.
