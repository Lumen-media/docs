Module locales

Expand description

Translation (i18n) management.

Locale JSON files live in the app data directory under locales/ and are synced from the project’s GitHub releases. languages.json lists the available languages; each <code>.json maps translation keys to strings. Synced files are size-capped and scanned for active content (inline scripts / javascript: URLs) before being written to disk.
