Module backgrounds 

Source
Expand description

Generator background engine, authored in Rust.

This module is the source of truth for the generator catalog: effect definitions, parameter schemas, WGSL sources, shader assembly and the WGSL -> GLSL ES 3.00 conversion. The frontend never declares effects or parameter semantics; it consumes the bundle produced by cargo run --example bg_compile, and background_presets validates user presets against the same catalog.
