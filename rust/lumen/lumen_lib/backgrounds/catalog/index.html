lumen_lib::backgrounds

Module catalog 

Source
Expand description

Static catalog for the generator backgrounds: every effect documented in docs/architecture/generator-backgrounds-plan.md that a single fragment pass can render (Tier 0) plus the Tier 1 feedback set.

Parameter order is meaningful: effect-specific parameters are packed into u_extra in declaration order, and uniform_index records the slot.
